Methodology

  • Every lookup is written to evidence_manifest.jsonl with a timestamp, source and SHA-256 hash of the response.
  • Entity labels come from public Etherscan name tags; unlabeled addresses are shown as shortened hashes.
  • Search Out matches outgoing transfers by USD value using hourly prices at the time of each transaction.
Runs locally. API keys stay in .env and are never sent to the browser. Leads only — verify findings against primary sources before relying on them.
